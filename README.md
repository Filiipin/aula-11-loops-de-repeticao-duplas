## Instruções para executar cada programa

### Para executar os códigos desenvolvidos nas três linguagens, certifique-se de ter os respectivos ambientes instalados em sua máquina (JDK para Java, .NET SDK para C# e Cargo/Rust para Rust).

### 1. Executando a versão em Java

1. Abra o terminal e navegue até a pasta do projeto Java:
   ```bash
   cd java/

2. Compile o código:
   ```Bash
   javac Main.java

3. Execute o programa:
   ```Bash
   java main

---

### 2. Executando a versão em C#

1. Abra o terminal e navegue até a pasta do projeto C#:
   ```Bash
   cd csharp/

2. Execute o projeto utilizando o .NET CLI:
   ```Bash
   dotnet run

---

### 3. Executando a versão em Rust

1. Abra o terminal e navegue até a pasta do projeto Rust:
   ```Bash
   cd rust/

2. Compile e execute o projeto utilizando o gerenciador Cargo:
   ```Bash
   cargo run
